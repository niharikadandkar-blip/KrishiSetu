# KRISHISETU PRODUCT PRINCIPLES

Future AI agents and developers working on this codebase MUST follow these principles:

1. **FARMER-FIRST & ADAPTIVE UX**:
   Never force the farmer to learn complex navigation. Use visual cards, large touch targets, regional language strings, and low-literacy-friendly controls.

2. **NO FAKE FUNCTIONALITY OR FALSE CLAIMS**:
   Never display static mock data as "Live API Data". Never claim official government verification (e.g. "Verified by DigiLocker") unless a real integration has returned an authentic result.

3. **NON-BLOCKING ONBOARDING**:
   Registration + OTP + Location = Immediate App Access. Identity verification is a trust layer required only when attempting high-trust marketplace actions.

4. **DECOUPLED PRODUCTION-READY ARCHITECTURE**:
   Maintain clear separation between UI, API handlers, Service Layer, Repositories, and Database ORM. Do not depend on temporary local dev tools (like SQLite) in core business logic.

5. **PROBABILISTIC & EVIDENCE-BASED AI**:
   AI features must explain their supporting evidence, data timestamps, and level of uncertainty. Never make deterministic financial or price guarantees.
