# Feature Decision Framework: What to Build vs What NOT to Build

## DO NOT BUILD (or Build Only If Validated Post-Phase 6)

1. **Generic E-Commerce Input Store**:
   - *Why*: Competitors like AgroStar and DeHaat already spend heavily on input supply chains. Adding input e-commerce distorts KrishiSetu's core focus on farmer-market linkage and creates inventory risk.

2. **Deterministic AI Price Prediction**:
   - *Why*: Agricultural market prices depend on unpredictable weather, policy shifts (export bans, import duties), and local trader cartels. Claiming exact future prices destroys trust when predictions fail.

3. **Fake Live Data / Fake Verification**:
   - *Why*: Displaying mock data as "Live API Data" or fake badges as "Verified by DigiLocker" creates legal risks and destroys credibility.

4. **Complex Futures & Derivatives Trading**:
   - *Why*: High risk, highly regulated, and inappropriate for smallholder farmers.

---

## STRONG VALIDATED OPPORTUNITIES (To Build Phase-by-Phase)

1. **Phase 1 (Implemented)**: Canonical Onboarding, Language Selection (Marathi/Hindi/English), Role Selection, Development OTP, Location Selector, Main App Dashboard, DigiLocker-Ready Verification Gate.
2. **Phase 2**: Farmer & Buyer Profile Extension + Location Intelligence.
3. **Phase 3**: Crop Listings + Marketplace Discovery.
4. **Phase 4**: Fixed Price & Bidding/Offer Negotiation Engine.
5. **Phase 5**: Transaction Tracking & Order Status.
6. **Phase 6**: Transport & Storage Aggregation.
7. **Phase 8**: Market Intelligence & Net Realization Calculation.
8. **Phase 10-11**: Voice Interactions & Probabilistic AI Task Assistant.
